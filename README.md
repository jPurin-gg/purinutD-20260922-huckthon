# utd_hack — 昼めし（モック）

長岡周辺の昼ごはんのお店を「いま営業中かどうか」で探し、みんなで候補を出し合うためのスマホ向け Web アプリのモックです。
バックエンドなし、単一 HTML ファイルで動きます。

## 使い方

`lunch-list-mock.html` をブラウザで開くだけで動きます。

```sh
open lunch-list-mock.html
```

スマホ表示（幅 560px 以下）を想定したレイアウトです。PC で確認する場合はデベロッパーツールのデバイスモードを使うと見やすいです。

## 画面構成

- **一覧タブ**
  - 現在時刻（または任意の時刻）で「営業中 / まもなく閉店 / 閉店」を判定して表示
  - カテゴリ・営業中のみ・並び替えでフィルタ
  - 行タップで詳細シート（写真ギャラリー、営業時間、価格帯、Google マップへのリンク）
  - 「＋」でボードに候補として追加
- **ボードタブ**
  - 候補にしたお店とメモをカード形式で並べて表示
  - 各カードに 👍 で投票、× で削除
  - 「今日はカレーの気分」などのメモをボードに貼れる
- 左右スワイプ、または上部タブでページを切り替え
- ダークモード対応（OS 設定に追従）

## 補足

- 店舗データ・営業時間・写真はすべてダミーです（固定シードの乱数で生成）。
- ボードの同期機構はローカル保持のみのスタブです。
- 外部依存は Google Fonts（Zen Kaku Gothic New / Dela Gothic One）のみ。
