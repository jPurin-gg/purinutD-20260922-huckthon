# 要件定義書

## 目的
- 大学生のエンジニア団体において、MTG後の飯の行き先を決めるのにかかる時間を減らして開発に取れる時間を増やす

**解決したい課題**：飯を決めるのに時間がかかる

## ユースケース
大学生のエンジニア団体に所属する学生たちが、ミーティング後のご飯に行く際に使用する

## ターゲット
大学生のエンジニア団体に所属する学生
学部1年生〜修士2年生、3~10人

## 提供できる顧客価値
- ランチの行き先を決めるにかかる時間を短縮する
  - （毎週平均で2回くらいMTGがあり、毎回30分かかるランチの行き先を考える時間を10~20分短縮できたら、週に20~40分ほど時間に余裕ができて、開発に使える時間が増える）
- 土地勘のない人でも美味しいランチ先を選べるようになる

## ユーザへの影響（良いこと・悪いこと（ある世界線・ない世界線））
- ある世界線
    - 良いこと
        - ランチを決めるのにかかる時間がへる
        - 知らないランチ先を見つけることができる
    - 悪いこと
        - アプリを起動する手間がかかる
        - アプリの存在を周知する必要がある
        - アプリの保守に工数がかかる
- ない世界線
    - 良いこと
    - 悪いこと
        - ランチの行き先を決めるのに30分くらいかかることがある
        - それに時間がかかってランチの話が流れることもある
        - 土地勘がない人だけでランチの行き先を決めるのが難しい

## 背景
大学生のエンジニア団体に所属する学生たちが、ミーティング後のご飯に行くのが恒例になっているが、ランチの行き先を決めるのに30分くらいかかることがある
